# P04 – Web-MVP (Meilenstein M1, Teil 2)

**Ziel:** Erstes sichtbares Produkt. `pnpm dev` startet die App; ein Projektordner wird per Klick
oder Drag & Drop geladen, analysiert (mit Fortschrittsbalken), und der App-Graph erscheint:
Kreise, Labels, Pfeile, Kraft-Layout, automatisch eingepasst. Optik der Toolbar und Upload-Karte
entspricht bereits dem Altsystem.
